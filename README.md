# SNS Danışmanlık web sitesi

snsdanismanlik.com.tr adresinde yayınlanan sitenin dosyaları.

- `index.html`: sitenin tamamı
- `kurlar.json`: TCMB döviz alış kurları, hafta içi her gün 15:50'de otomatik güncellenir
- `duyurular.json`: TÜRMOB mevzuat sirkülerleri ve İSMMMO duyuruları, günde üç kez otomatik güncellenir
- `araclar/`: bu iki dosyayı güncelleyen betikler
- `404.html`: eski adreslerden gelenleri ana sayfaya yönlendirir
- `CNAME`: alan adı tanımı
